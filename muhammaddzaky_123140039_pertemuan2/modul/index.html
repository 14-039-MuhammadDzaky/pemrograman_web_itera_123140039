Materi 01 Demo 1 & 2

Let, Const & Arrow Functions

Deklarasi variabel modern dengan block-scope, proteksi mutasi nilai, dan penulisan fungsi ringkas berkarakteristik lambda.

  • let vs var
  • const immutability
  • Implicit return
  • Lambda syntax
Materi 02 Demo 3

Template Literals

Interpolasi string dinamis dengan ekspresi JavaScript `${...}` dan kemudahan penyusunan string multi-baris tanpa karakter escape `\n`.

  • Interpolasi ${}
  • Multi-line Strings
  • Expression Parsing
  • HTML Rendering
Materi 03 Demo 4 & 5

Destructuring, Spread & Rest

Pembongkaran properti objek/array bertingkat secara ekspresif serta pemanfaatan operator titik tiga (`...`) untuk kloning dan rest parameter.

  • Nested Object
  • Spread Immutability
  • Rest Parameter
  • Swap Variables
Materi 04 Demo 6, 7 & 8

Classes & Object Literals

Pemrograman berorientasi objek modern dengan sintaks class, pewarisan sifat (`extends`), konstruktor `super`, getter/setter, dan properti dinamis.

  • ES6 Classes
  • Inheritance / extends
  • Default Parameters
  • Computed Keys
Materi 05 Demo 9 & 10

Modern Array Methods

Pengolahan data koleksi deklaratif menggunakan Higher-Order Functions: `map()`, `filter()`, `reduce()`, `find()`, `flat()`, dan method chaining.

  • map, filter, find
  • reduce agregasi
  • Method Chaining
  • flat & includes
Materi 06 Demo 11 & 12

Async Programming

Manajemen operasi asinkron non-blocking menggunakan Promise chaining, Promise.all/race, serta sintaks modern bersih `async/await` dengan `try/catch`.

  • Promises (.then/.catch)
  • Promise.all & race
  • Async / Await
  • Parallel Fetching
